# Phase 2: Eliminate Duplicate URLs

The largest issue: duplicate `.html` and extensionless URLs ranking for the same queries, splitting authority between them.

Known examples:

```text
/pagar-agua-monterrey.html      ↔  /pagar-agua-monterrey
/pagar-cfe-guadalajara.html     ↔  /pagar-cfe-guadalajara
/pagar-agua-cdmx.html           ↔  /pagar-agua-cdmx
/pagar-agua-guadalajara.html    ↔  /pagar-agua-guadalajara   (confirm non-.html route exists; create if not)
/pagar-cfe-monterrey.html       ↔  /pagar-cfe-monterrey       (confirm non-.html route exists before redirecting — don't redirect into a 404)
```

There may be additional duplicates beyond this list — find and fix all of them; report anything found that wasn't already known.

For each duplicate:

1. Keep the extensionless URL as canonical.
2. Add a permanent **301** redirect from the `.html` URL (no JavaScript or meta-refresh redirects).
3. Add a self-referencing canonical tag to the preferred page, using the full absolute URL, e.g.:
   ```html
   <link rel="canonical" href="https://pagoyamx.com/pagar-agua-monterrey">
   ```
4. Remove the `.html` duplicate from the sitemap.
5. Update all internal links (nav, buttons, city links, related-service links, footer) to point directly to the extensionless URL — none should pass through a redirect.
6. Confirm no redirect chains or loops exist.

* Titles ~45–60 characters; primary search phrase near the beginning; brand name near the end when space allows; unique per page; no keyword stuffing.
* Descriptions ~130–160 characters; state exactly what the user can do; mention city/service where relevant; natural Mexican Spanish; unique per page.
