CREATE TABLE IF NOT EXISTS landlords (
  id SERIAL PRIMARY KEY,

  full_name TEXT NOT NULL,
  email TEXT NOT NULL UNIQUE,
  whatsapp TEXT,

);

PART 3 — BACKEND UTILITY: generateLandlordCode()
═══════════════════════════════════════════════════════════════

Create file: server/utils/landlordCode.ts

```typescript
import { db } from '../db';  // use whatever the existing db import path is

export async function generateLandlordCode(): Promise<string> {
  // Find the highest existing LNDnnn code
  const result = await db.query(
    `SELECT landlord_code FROM landlords 
     WHERE landlord_code ~ '^LND[0-9]+$' 
     ORDER BY CAST(SUBSTRING(landlord_code FROM 4) AS INTEGER) DESC 
     LIMIT 1`
  );
  
  if (result.rows.length === 0) {
    return 'LND001';
  }
  
  const last = result.rows[0].landlord_code; // e.g. "LND003"
  const num = parseInt(last.replace('LND', ''), 10);
  const next = num + 1;
  return 'LND' + String(next).padStart(3, '0'); // LND004, LND027, LND100 etc.
}
```

PART 4 — BACKEND ROUTES: /api/landlords/*
═══════════════════════════════════════════════════════════════

Create file: server/routes/landlords.ts

Implement the following 4 routes:

────────────────────────────────────────────────────────────────
POST /api/landlords/register
────────────────────────────────────────────────────────────────
Body: { full_name, email, whatsapp?, units?, city?, notes? }

Logic:
1. Validate full_name and email are present. Return 400 if missing.
2. Check if email already exists in landlords table. Return 409 if duplicate.
3. Call generateLandlordCode() to get next code (e.g. LND004).
4. Construct referral_link: 
   `https://pagoyamx.com/registro?ref=${landlordCode}`
5. Insert new row into landlords table with all fields + landlord_code + referral_link.
6. Send Twilio WhatsApp notification to admin using the existing 
   Twilio/WhatsApp pattern in the codebase. Message:
   "🏠 Nuevo propietario registrado en PagoYa
   Código: ${landlordCode}
   Nombre: ${full_name}
   Email: ${email}
   Unidades: ${units || 1}
   Link: ${referral_link}"
7. Return 201 with: { landlord_code, referral_link, full_name, email }

────────────────────────────────────────────────────────────────
GET /api/landlords/:code
────────────────────────────────────────────────────────────────
Returns the landlord row matching landlord_code. 
Include: landlord_code, full_name, email, units, referral_link, 
         referred_users, total_commission_mxn, status, created_at.
Return 404 if not found.

────────────────────────────────────────────────────────────────
GET /api/landlords/:code/stats
────────────────────────────────────────────────────────────────
Returns:
{
  landlord_code,
  full_name,
  referred_users: COUNT of users where referred_by_landlord = :code,
  activated_users: COUNT of users where referred_by_landlord = :code 
                   AND has at least one completed transaction 
                   (join to transactions or payments table using 
                    whatever the existing completed-payment pattern is),
  total_commission_mxn: referred_users * 150,
  pending_commission_mxn: activated_users not yet marked paid * 150
}

────────────────────────────────────────────────────────────────
GET /api/landlords (admin only — protect with existing X-Admin-Key middleware)
────────────────────────────────────────────────────────────────
Returns all landlords ordered by created_at DESC.
Include all columns. Used by admin dashboard.

Register all 4 routes in the main server app file (app.ts or index.ts or 
server.ts — wherever existing routes are registered):
  import landlordRoutes from './routes/landlords';
  app.use('/api/landlords', landlordRoutes);

PART 6 — TRIGGER LANDLORD COMMISSION ON FIRST PAYMENT
═══════════════════════════════════════════════════════════════

In the existing payment completion handler (wherever a bill payment is 
marked as completed/successful in the codebase):

1. Check if the paying user has referred_by_landlord set.
2. Check if this is the user's FIRST completed payment

3. If both true:
   a. Add 150 to landlords.total_commission_mxn for that landlord_code.
   b. Send Twilio WhatsApp to admin:

      Inquilino: ${user_phone or user_id}
      Comisión: $150 MXN
