async payBill(req):

       3133=sku_not_found, 8888=communication_error
  4. If requestTXN success === true: store transID, start polling
  5. Poll statusTXN every 5 seconds, max 60 seconds total
  6. If statusTXN success === true: return confirmed result with
     Folio, TransID, Carrier, Monto, Cargo from response data
  7. If statusTXN times out (60 sec): return pending result
     - Store transID in bill_payments.external_tx_id
     - Status = 'pending' not 'failed'
  8. If statusTXN success === false with data: return failed
