SCREEN: 'otp'
─────────────────────────────────────────
Triggered when POST returns { status: 'otp_required' }

Store phone in a useRef (not state) so it persists 
across renders without causing re-renders.

Show:
- Heading: "Verifica tu número"
- Subtext: "Enviamos un código de 6 dígitos por WhatsApp 
  al ****[last 4 digits of phone]"
- Six individual single-character inputs in a row
  - Each input: type="tel", maxLength=1, 48x48px minimum
  - Auto-advance focus to next input on digit entry
  - Backspace on empty input moves focus to previous input
  - On paste: distribute digits across boxes automatically
- "Verificar" button (full width, same style as existing submit button)
- "Reenviar código" text link below button:
  - Shows countdown "Reenviar en 60s" for 60 seconds
  - After 60s becomes tappable, styled as a link
  - On tap: re-POSTs original form payload to 
    /api/street-team/signup-with-bonus to trigger new OTP
    Resets 60s countdown
- Error message area: hidden by default, shows below inputs

OTP input refs: use an array of useRef for the 6 boxes
so focus management works correctly in React.

On "Verificar" tap:
  POST to /api/street-team/verify-bonus-otp:
  { phone: phoneRef.current, code: digits.join('') }

  { verified: false, reason: 'invalid' }:
    Show: "Código incorrecto. Inténtalo de nuevo."
    Clear all 6 inputs, focus first box

  { verified: false, reason: 'expired' }:
    Show: "El código expiró. Solicita uno nuevo."
    Disable inputs and verify button
    Make resend link immediately active

  { verified: false, reason: 'max_attempts' }:
    Show: "Demasiados intentos. Solicita un nuevo código."
    Disable inputs and verify button
    Make resend link immediately active

  { success: true }:
    Store bonusCredited and bonusAmount in state
    Set screen = 'success'
