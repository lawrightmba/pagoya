4. Grand Prize API Endpoint — Existence & Graceful Failure
Search api-server/src/routes/ for a /games/grand-prize GET endpoint.
If it exists: confirm it returns { prize_amount: 0, total_entries: 0 } (or similar) when no prize is configured rather than a 404 or unhandled error.
If it does NOT exist: create it at the correct route file. Minimum viable implementation:
typescriptrouter.get("/games/grand-prize", async (req, res) => {
  try {
    // Query grand prize config from DB — return safe defaults if not configured
    const result = await db.query.grandPrizeConfig?.findFirst({
      where: (t, { eq }) => eq(t.is_active, true)
    });
    res.json({
      prize_amount: result?.prize_amount ?? 0,
      total_entries: result?.total_entries ?? 0,
      draw_date: result?.draw_date ?? null
    });
  } catch (err) {
    // Never 500 on homepage — always return safe defaults
    res.json({ prize_amount: 0, total_entries: 0, draw_date: null });
  }
});

5. Admin Route Auth Guard
Open api-server/src/routes/ and confirm there is a middleware guard on any route prefixed /admin or serving admin data that checks for a valid session or API key before responding.
If the guard exists: leave it. Add a comment // Admin auth guard — verified pre-publish [June 2026].
If no guard exists: add a simple middleware check:
typescriptconst adminAuth = (req: Request, res: Response, next: NextFunction) => {
  const key = req.headers["x-admin-key"] || req.query.adminKey;
  if (key !== process.env.ADMIN_SECRET_KEY) {
    return res.status(401).json({ error: "Unauthorized" });
  }
  next();
};
Apply it to all /admin/* routes. Add ADMIN_SECRET_KEY to the list of required env vars in your README or .env.example.
