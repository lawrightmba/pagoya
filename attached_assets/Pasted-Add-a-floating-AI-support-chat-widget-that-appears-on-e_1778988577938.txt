New file: artifacts/api-server/src/routes/agentChat.ts
Mount at /api/agent/chat in routes/index.ts after all existing routes.

POST /api/agent/chat
Body: { message: string, telefono?: string, history: Array<{role: "user"|"assistant", content: string}> }

The route has two modes determined by whether telefono is present and valid (10 digits):

TOOL DEFINITIONS — define these as Anthropic tool_use tools:

tool: get_payment_history
  - Input: { telefono: string }
  - Action: query bill_payments WHERE telefono = $1 ORDER BY created_at DESC LIMIT 10
  - Return: array of { service_name, amount, fee, status, provider_used, created_at }

tool: get_wallet_balance
  - Input: { telefono: string }
  - Action: query wallets WHERE telefono = $1
  - Return: { balance_mxn, updated_at } or null if not found

tool: get_pending_oxxo
  - Input: { telefono: string }
  - Action: query wallet_transactions WHERE telefono = $1 AND type='oxxo_pending' AND created_at > now() - interval '48 hours'
  - Return: array of { amount, created_at, reference }

tool: escalate_to_support
  - Input: { telefono: string, issue_summary: string }
  - Action: send WhatsApp via existing Twilio client to process.env.ADMIN_WHATSAPP_NUMBER
  - Message: "🆘 Soporte PagoYa requerido\nUsuario: [telefono]\nProblema: [issue_summary]"
  - Return: { escalated: true }

SYSTEM PROMPT (pass as system parameter to anthropic.messages.create):
"""
Eres el asistente de soporte de PagoYa, una app mexicana de pago de servicios y recargas. Ayudas a usuarios con dudas sobre sus pagos, saldo, y servicios disponibles.

Servicios disponibles: CFE, Telmex, Telcel, Izzi, Totalplay, Sky, Megacable, AT&T, Movistar, agua, internet y más. Costo por transacción: $15 MXN. Formas de cargar saldo: efectivo en OXXO, tarjeta de débito/crédito, transferencia SPEI. Puntos de lealtad: 1 punto por cada $10 MXN pagados, con niveles Bronze, Silver, Gold.

Cuando el usuario pregunta sobre SU cuenta específica (su saldo, sus pagos, su depósito), usa las herramientas disponibles para consultar su información real antes de responder. No inventes datos.

Cuando el usuario reporta un problema que no puedes resolver (pago fallido sin reembolso, cuenta bloqueada, disputa), usa escalate_to_support y confirma al usuario que un agente humano los contactará pronto.

Responde siempre en el mismo idioma que el usuario. Si escribe en español, responde en español. Si escribe en inglés, responde en inglés. Sé conciso — máximo 3 oraciones por respuesta salvo que el usuario pida más detalle. No menciones que eres Claude ni que usas IA de Anthropic.
"""

CALL PATTERN:
- Pass history array directly as the messages parameter (already formatted as {role, content} pairs)
- Append the new user message to history before sending
- Use model: "claude-haiku-4-5" (same as autofill)
- max_tokens: 1024
- Include the 4 tools in the tools array
- Handle tool_use response blocks: when the model returns a tool_use block, execute the corresponding DB query or action, then send the result back as a tool_result message, then call anthropic.messages.create again to get the final text response
- Return to frontend: { reply: string, escalated: boolean }
- Wrap everything in try/catch — on error return { reply: "Lo sentimos, ocurrió un error. Intenta de nuevo.", escalated: false }
