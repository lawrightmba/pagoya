# PagoYa PTI Score — Replit Agent Prompt

## Context

PagoYa is a WhatsApp-native fintech wallet built on TypeScript / Express / PostgreSQL / Drizzle ORM, hosted on Replit. The existing schema includes: `users`, `transactions`, `wallet_loads`, `missions`, `user_missions`, `loyalty_points`. A `pti_score` column may or may not exist on the users table — check before adding.

We are building two things:

1. **A nightly cron job** that computes a PTI (PagoYa Trust Index) score (0–100) for every user and writes it back to the users table, along with a score breakdown JSON and a computed_at timestamp.
2. **A user-facing trust score widget** that appears on the dashboard after first login post-registration, and on every subsequent login, showing the user their score, a plain-Spanish explanation of what drives it, and what they can do to improve it.

There is NO fee or paywall on score refreshes at this time. Every user sees their score for free. The score updates monthly via the cron — do not build any premium refresh flow.

## Part 2 — PTI computation service

Create file: `lib/services/pti.ts`

### Score formula (0–100, integer)

Compute each component independently. Cap total at 100. Store breakdown as JSON so the frontend can explain each component to the user.

```typescript
interface PTIBreakdown {
  payment_streak:     { score: number; weeks: number; max: number };
  biller_diversity:   { score: number; count: number; max: number };
  kyc_verified:       { score: number; verified: boolean; max: number };
  wallet_balance:     { score: number; avg_balance_mxn: number; max: number };
  mission_completions:{ score: number; count: number; max: number };
  load_spend_ratio:   { score: number; ratio: number; max: number };
  account_age:        { score: number; days: number; max: number };
  total:              number;
}
```

### Component rules

| Component | Max pts | Logic |
|---|---|---|
| `payment_streak` | 25 | streak_weeks from user_missions WHERE mission_key = 'streak_weeks'. 1pt per week, cap 25. |
| `biller_diversity` | 15 | COUNT(DISTINCT biller_id) from transactions WHERE user_id = ? AND status = 'success'. 5pts per distinct biller, cap 15. |
| `kyc_verified` | 15 | 15pts if kyc_submitted_at IS NOT NULL, else 0. |
| `wallet_balance` | 15 | Average of last 30 days of EOD balance snapshots if available, else current balance. <$50 MXN = 0pts, $50–$199 = 5pts, $200–$499 = 10pts, $500+ = 15pts. |
| `mission_completions` | 15 | COUNT of completed missions from user_missions WHERE completed_at IS NOT NULL. 3pts each, cap 15. |
| `load_spend_ratio` | 10 | SUM(wallet_loads) / SUM(spend) over last 90 days. ratio >= 1.0 = 10pts, 0.7–0.99 = 7pts, 0.4–0.69 = 4pts, <0.4 = 0pts. If no loads yet = 0pts. |
| `account_age` | 5 | Days since created_at. <7 days = 0pts, 7–29 = 2pts, 30–89 = 3pts, 90+ = 5pts. |

**Total = sum of all components, capped at 100.**

### Score tier labels

```typescript
function getPTITier(score: number): { tier: string; color: string; label: string } {
  if (score >= 80) return { tier: 'excelente',  color: '#00C875', label: 'Excelente' };
  if (score >= 60) return { tier: 'bueno',      color: '#007A4A', label: 'Bueno' };
  if (score >= 40) return { tier: 'en_proceso', color: '#F59E0B', label: 'En proceso' };
  return           { tier: 'iniciando',          color: '#6B7280', label: 'Iniciando' };
}
```

### Export the compute function

```typescript
export async function computePTIForUser(userId: number, db: DrizzleDB): Promise<PTIBreakdown>
export async function computePTIForAllUsers(db: DrizzleDB): Promise<void>
```

`computePTIForAllUsers` should:
- Select all user IDs
- For each user, call `computePTIForUser`
- Write result back: `UPDATE users SET pti_score = ?, pti_breakdown = ?, pti_computed_at = NOW(), pti_first_computed_at = COALESCE(pti_first_computed_at, NOW()) WHERE id = ?`
- Log success/failure per user without throwing — one bad user should not stop the batch
- Log total: "PTI batch complete: X users updated, Y errors"

## Part 3 — Cron job

Create file: `lib/cron/pti-cron.ts`

Use `node-cron` (already installed, or add it). Schedule: **1st of every month at 3:00 AM Mexico City time (UTC-6)**.

```typescript
import cron from 'node-cron';
import { computePTIForAllUsers } from '../services/pti';
import { db } from '../db';

// Runs 1st of month at 03:00 AM UTC-6 (09:00 UTC)
cron.schedule('0 9 1 * *', async () => {
  console.log('[PTI Cron] Starting monthly PTI computation...');
  try {
    await computePTIForAllUsers(db);
    console.log('[PTI Cron] Complete.');
  } catch (err) {
    console.error('[PTI Cron] Fatal error:', err);
  }
});
```

Register the cron in `api-server/index.ts` (or wherever the main server starts) by importing the cron file:

```typescript
import '../lib/cron/pti-cron';
```

## Part 4 — API endpoints

Add to the existing Express router.

### GET /api/pti/score

Returns the current user's PTI score, breakdown, tier, and next update date.

```typescript
// Middleware: requires auth (existing JWT middleware)
GET /api/pti/score

Response 200:
{
  score: 67,
  tier: "bueno",
  tier_label: "Bueno",
  tier_color: "#007A4A",
  breakdown: {
    payment_streak:      { score: 16, weeks: 16, max: 25 },
    biller_diversity:    { score: 10, count: 2,  max: 15 },
    kyc_verified:        { score: 15, verified: true, max: 15 },
    wallet_balance:      { score: 10, avg_balance_mxn: 320, max: 15 },
    mission_completions: { score:  9, count: 3, max: 15 },
    load_spend_ratio:    { score:  7, ratio: 0.85, max: 10 },
    account_age:         { score:  3, days: 45, max: 5 }
  },
  computed_at: "2026-06-01T09:00:00Z",
  next_update: "2026-07-01",
  is_new_user: false   // true if pti_score IS NULL (never computed yet)
}

// If score not yet computed (new user):
Response 200:
{
  score: null,
  is_new_user: true,
  message: "Tu primer puntaje se calculará el próximo día 1 del mes."
}
```

### POST /api/pti/compute-now (admin only)

Triggers immediate computation for a single user. Protected by admin middleware.

```typescript
POST /api/pti/compute-now
Body: { telefono: string }
Response: { score: number; breakdown: PTIBreakdown }
```
