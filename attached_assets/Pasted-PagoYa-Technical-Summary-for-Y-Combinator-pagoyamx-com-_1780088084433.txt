2. Agentic AI — Paula
Paula is a Claude-powered AI agent running a tool-use loop across two simultaneous channels: WhatsApp (inbound) and an in-app floating widget on every product page. She is not a chatbot — she takes real actions against live user data.
Tool Set (live today)
Tool	What It Does
get_wallet_balance	Returns exact MXN balance in real time from the wallets table
get_payment_history	Retrieves and narrates recent transactions in natural Spanish
get_pending_oxxo	Checks if a cash deposit voucher is still pending confirmation
escalate_to_support	Hands off to human agent via WhatsApp with full conversation context

Deployment Architecture
•	WhatsApp inbound: any message to the PagoYa number routes through the Paula agent loop. First-contact messages screened for rep referral codes before entering the agent flow.
•	In-app widget: persists across every screen with localStorage session memory, typing indicator, escalation banner.
•	Post-payment hook: after every successful payment the app auto-opens Paula's chat after 4 seconds with pre-filled payment context — turns a receipt into a retention event.
•	AI bill autofill: home screen natural-language input parses 'CFE 350 pesos' and pre-fills service, amount, and reference in one shot via Claude.

Contextual Paula Hints (live as of May 2026)
Paula surfaces inline at 6 high-friction points across the product — not as a chat prompt, but as a contextual nudge that pre-loads her with the exact question the user is most likely stuck on. One tap opens the full agent conversation.
●	Registration — CURP field: “¿No sabes tu CURP? Paula puede ayudarte a encontrarla.”
●	OTP screen: Troubleshooting prompt triggered after a failed or expired code — Paula walks the user through resend and WhatsApp delivery issues.
●	Payment form — reference number field: “¿Dónde encuentro mi número de referencia?” — pre-loaded with biller context so Paula can give a biller-specific answer.
●	Payment review screen — fee line: “¿Por qué hay una comisión de $25 MXN?” — Paula explains the fee and positions it against the cost of a trip to OXXO.
●	Cash load screen — OXXO deposit: Step-by-step OXXO deposit guidance — how to show the barcode, how long confirmation takes, what to do if the deposit doesn’t reflect.

Each hint is a single tap that pre-loads Paula’s context — users never have to describe their situation from scratch. This pattern reduces support escalations at the exact moments users are most likely to abandon.

3. Payment Infrastructure
Wallet Architecture
Every user has a wallets row linked by phone. All debits and credits are atomic DB transactions — a bill payment deducts the wallet and records the transaction in a single operation. No partial states.
Transaction Type	Source	Badge Color	Status
load_oxxo	Digital Femsa barcode	Coral	pending → completed via webhook
load_card	Conekta tokenized card	Purple	completed on charge.paid webhook
load_spei	SPEI inbound transfer	Blue	completed on bank webhook
bill_pay	SIPREL / Evoluciona	Red debit	atomic with wallet debit
SIGNUP_BONUS	Street team referral	Green	credited post OTP verification
p2p_send / p2p_receive	User-to-user transfer	Orange	atomic debit + credit

Bill Pay Rail
•	Primary: SIPREL — 20+ billers including CFE, Telmex, Telcel, IZZI, Sky, and streaming services
•	Fallback: Evoluciona Movil — auto-failover if SIPREL returns an error
•	Fee: $25 MXN flat per transaction, deducted atomically from wallet
•	Loyalty: 1 pt per $10 MXN paid; Bronze/Silver/Gold multipliers; redeemable for wallet credit or fee waiver token

4. Street Team Referral & OTP Onboarding
Reps recruit users in the field with unique QR codes. The signup flow is fully gated by WhatsApp OTP before any wallet or user record is created.
Signup Flow (3 screens)
Step	What Happens	Fraud Guard
Form	Name, phone (international E.164), CURP, colonia, ref_code captured	Phone + CURP duplicate check before OTP fires
OTP	6-digit code sent via Twilio WhatsApp, 5-min TTL, 3-attempt limit	generateOTP resets on resend; max_attempts blocks without expiring session
Bonus Credit	Wallet credited $25-50 MXN via SIGNUP_BONUS transaction	Idempotency lock on signup_bonus_claimed; rep velocity check (warn @10/hr, block @20/hr)

Rep Dashboard
•	Self-serve QR code generation via api.qrserver.com — downloadable, printable
•	Shareable signup link with one-tap clipboard copy
•	Live recruitment stats: referidos count, bonos acreditados, valor total MXN
•	Commission tracker: $5 MXN per confirmed payment, 7-day hold, bulk payout management
•	Admin BONOS tab: toggle bonus on/off, set amount ($25/$50), eligible rep codes, velocity thresholds, fraud log
