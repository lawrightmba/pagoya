**Changes from REV 4:**
1. **Canonical amount column resolved:** `monto` (numeric, notNull), written identically by all four insert paths in `billpay/routes/billpay.ts`, already used by every v4.2 scoring path. `platform_fee_mxn` is the fee. `amount_due_mxn` is never populated — do not use. `bill_amount` is a legacy non-ORM orphan — ignore.

Bill-shock and any future "paid vs. owed" feature must be defined on transacted amount and documented as such, so nobody later assumes it measures deviation from a true bill amount.
4. **Biller grouping key confirmed as `service_id`**, in preference to `service_name`/`empresa` (a legacy column) — the two follow-up UPDATE paths use `COALESCE(service_name, empresa, ...)` for display purposes only, which is not stable enough for grouping.
