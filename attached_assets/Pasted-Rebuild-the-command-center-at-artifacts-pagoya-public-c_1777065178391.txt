IMPLEMENTATION REQUIREMENTS
─────────────────────────────────────────

1. All three proxy endpoints (/api/hubspot/contacts/count, 
   /api/mahali/stats, /api/mahali/selcom-status, /api/stripe/status) 
   must be added to the PagoYa Express server (server/index.ts or 
   wherever routes are registered)

2. Each endpoint must:
   - Return JSON
   - Handle errors gracefully — if the external call fails, return 
     { error: true, fallback: LAST_KNOWN_VALUE } so the dashboard 
     shows the last known value instead of breaking
   - Log errors to console but never crash

3. In the command center HTML:
   - On DOMContentLoaded, call all 4 endpoints simultaneously using 
     Promise.allSettled()
   - Update each stat element by ID when data returns
   - Show a subtle animated pulse on each stat while loading
   - After load, set a 60-second interval to refresh all stats
   - If a stat fails to load, show the last cached value with a 
     small grey "~" prefix to indicate it may be stale

4. Add a "Live Data" indicator in the footer next to the version number:
   - Green dot + "Live" when last refresh was < 2 minutes ago
   - Amber dot + "Stale" when last refresh was > 2 minutes ago
   - Shows time of last successful refresh e.g. "Last updated 14:32"
